# Oracle Ads — robôs

Rotinas automáticas (GitHub Actions) do Oracle Ads:

- `robos.yml` — robôs que mineram a Biblioteca de Anúncios pública da Meta e medem a escala dos anunciantes.
- `grupo.yml` — posta no grupo gratuito de WhatsApp a cada 2h (8h–20h).
- `parear.yml` — pareia o número do bot por código (disparado pelo painel do dono).

Nenhum segredo fica no código: chaves em *Settings › Secrets*.
